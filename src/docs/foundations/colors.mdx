# Colors

Colors come from sparks.ds's variables, mirrored in `src/styles/theme.css`: primitive palettes, and semantic tokens that point to them. Each token is a CSS variable, such as `--primary`, and a Tailwind utility, such as `bg-primary` or `text-primary-foreground`.

Pair each surface token with its `-foreground` token, so text always has enough contrast. The swatches below read the live variables, so they always match the theme.
